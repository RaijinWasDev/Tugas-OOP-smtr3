# Portal Admin Sevima Mini

Jalankan Buka-Sevima.cmd, tunggu sampai server aktif, lalu buka http://127.0.0.1:8007/admin. Gunakan kunci dari terminal. Jika paket Python belum tersedia, jalankan python -m pip install -r requirements.txt di folder ini.

## Urutan presentasi

1. Masuk ke Pendaftaran dan pilih Tambah pendaftar. Gunakan data fiktif, lalu setujui pendaftar untuk menerbitkan NIM.
2. Buka KRS dan pilih mahasiswa tersebut. Tambahkan Algoritma untuk semester 1. Ajukan sebagai mahasiswa, lalu setujui sebagai dosen PA. Untuk menunjukkan revisi, pilih Minta revisi sebelum menyetujui.
3. Buka Jadwal. Simpan Algoritma untuk Senin 08.00–10.00, ruang A101, dosen D01. Coba simpan Basis Data pada jam, ruang, dan dosen yang sama untuk memperlihatkan bentrok. Geser menjadi 10.00–12.00 lalu simpan kembali.
4. Klik Keluar setelah selesai. Data tersimpan di akademik.db untuk sesi berikutnya.
